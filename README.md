# DSH 配置备份与恢复

**把 DeepSeek Harness 的配置与已安装插件清单打包为 ZIP，用于换机迁移、重装后恢复，以及复制一套调好的工作环境。**

**dsh-setting-backup · 配置导出 · 插件版本记录 · 工作台恢复**

## 什么是 dsh-setting-backup

**dsh-setting-backup** 是 DeepSeek Harness 的配置备份与恢复插件。它将当前配置和已安装插件清单（包含精确版本）一起保存到一个 ZIP 文件，方便在新环境中重新安装插件并恢复配置。

安装后，可从左侧栏 **「配置备份」** 或 **「设置 → 配置备份」** 打开页面，完成导出、导入、查看恢复进度和失败回退。

## 插件特性

**配置与插件清单 · 一起备份**

- **ZIP 导出** — 将配置和插件清单打包，方便保存、复制到新机器。
- **记录插件版本** — 保存导出时的实装版本，恢复时按清单安装。
- **另存为** — 导出后可另存备份文件，默认导出目录也保留一份副本。

**恢复工作台 · 进度可见**

- **导入预检** — 恢复前查看待安装插件、版本差异和本地来源提示。
- **自动安装插件** — 导入并完成第一次重启后，逐个安装清单中的插件，页面显示安装结果。
- **失败处理** — 查看「故障与日志」，选择「重试安装」或「整单回退」。

**按需携带 · 自己选择**

- **凭据可选** — 默认不导出凭据；勾选后备份包会标记为敏感，导入时需要再次确认。
- **携带本插件包** — 可选「同时包含本插件包」，供全新环境先安装恢复所需的插件。

## 适合哪些场景

- **换电脑**：把常用配置和插件清单带到新机器，减少逐项重新配置的工作。
- **重装环境**：提前保存备份，重装 DSH 后按清单恢复。
- **复用工作环境**：把调好的配置分享给另一套 DSH 环境，分享前确认备份是否包含凭据。

## 安装

从本项目 GitHub 仓库安装：

```bash
dsh plugin --profile desktop add github.com:shine96/dsh-setting-backup
```

也可以下载源码后从本地目录安装，路径请替换为实际存放位置：

```bash
dsh plugin --profile desktop add "D:/code/dsh-plugins/dsh-setting-backup"
```

以上命令以 `desktop` profile 为例；使用其他 profile 时，请替换成对应名称。安装完成后重启 DSH，打开 **「配置备份」** 即可使用。

> 新环境需要先安装本插件，才能打开导入页面。若导出时包含了本插件包，可先用包内的插件安装包完成安装。

## 快速开始

### 导出备份

1. 打开 **「配置备份」** 页面。
2. 按需选择「包含凭据」或「同时包含本插件包」。
3. 点击 **「导出 zip」**，等待备份生成。
4. 点击 **「另存为…」**，将备份保存到方便保管或迁移的位置。

默认备份位置：

```text
~/.dsh/setting-backup/exports/dsh-setting-backup-<yyyy-MM-dd_HH-mm-ss>.zip
```

上述路径以默认 `DSH_HOME` 为例，文件名使用本地时间。自定义 `DSH_HOME` 时，备份保存在该目录下的 `setting-backup/exports/`。

### 导入与恢复

1. 在目标环境打开 **「配置备份」**，选择备份 ZIP。
2. 查看预检结果，确认待安装插件、版本差异和需要手工处理的来源。
3. 确认导入，按页面提示完成 **第一次重启**。
4. 等待插件自动安装，查看安装结果；失败时可查看日志并重试。
5. 插件安装齐全、配置提交完成后，按提示完成 **第二次重启**。

```text
选择备份 → 预检并确认 → 重启① → 安装插件 → 提交配置 → 重启②
```

### 失败与回退

遇到安装失败时，先在 **「故障与日志」** 查看失败项和错误摘要，再点击 **「重试安装」**。需要放弃本次恢复时，可使用 **「整单回退」** 将配置恢复到导入前的状态。

## 使用须知

- **恢复会覆盖配置**：导入前请确认目标环境；插件会在导入时保存当前配置的本地快照。
- **备份范围**：包含配置与插件清单，不包含会话、附件、缓存、`node_modules` 或业务数据库。
- **安装需要可用来源**：备份记录插件清单，恢复时通常仍需从对应来源下载安装插件。
- **本地插件需额外准备**：`link:`、`file:` 等来源换机后可能不可用，需要手工准备；GitHub 等远端来源也受网络与资源可用性影响。
- **凭据妥善保管**：包含凭据的备份可能携带密钥等敏感信息，请勿上传到公开仓库或随意分享。
