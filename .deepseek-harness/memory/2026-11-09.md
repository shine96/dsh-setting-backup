## 环境必知
- **踩坑**：log_write_ops 的 ops 数组每个元素都必须自带 section 字段，即使多条写同一章节；漏传会被拒（section 不能为空），补上 section 重新提交即可。
- **踩坑**：Hindsight 未配置 apiToken 时知识库查询认证失败；需补齐认证配置后再查询。
- **踩坑**：dsh-ops standard 模式替换官方 glob 工具，文件扫描需使用 ops_glob。
- **踩坑**：dsh-ops standard 模式替换官方 read 工具时，直接调用 read 会失败；本地文件读取改用 ops_inspect_local_file。
- **踩坑**：沙箱阻止 node --test 创建子进程时，使用 test/all.mjs 同进程导入测试文件；本项目 npm test 已指向该 runner。
- **结论**：插件安装使用官方 dsh plugin add 入口维护依赖与 bundles；写 ~/.dsh/profile 范围需工作区外写入权限。
- **踩坑**：热重载成功回执不证明路由存活；本轮曾出现 disabled 与404，后续重载恢复200，需结合加载诊断与HTTP响应核实。
- **踩坑**：Windows 下 Bash 与 Node 对 /tmp 路径解析不一致，导致下载后读取失败；使用 mktemp 获取路径并经参数传给 Node 可修复。
